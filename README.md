# Fishing Game

A Roblox fishing game where real fishing knowledge matters: the right bait, spot and time of day decide what bites. Catch fish, earn coins, buy better gear, unlock new water. Built by Stewart (and later his son Liam) with Claude, in Roblox Studio.
