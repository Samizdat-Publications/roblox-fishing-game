# Home Pond Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A home pond beside the lake where players keep live fish from their bag; the fish grow and breed over real time, including while the player is away (capped), and can be sold later for more.

**Architecture:** Pond rules are a pure shared module (`PondLogic`) tested in Edit mode. The server owns pond data inside the player's save, ticks it on load (offline time, capped) and every 30 s while online, and answers pond actions through one RemoteFunction. The client shows a Pond panel (opened from the pond's prompt) and draws the player's own fish swimming in the pond.

**Tech Stack:** Luau in Roblox Studio, same layout and push path as v1 (`docs/superpowers/plans/2026-11-25-fishing-game-v1.md`).

**Spec:** `docs/DESIGN.md`, "Later versions" item 1: "Home pond: keep live fish; they grow and breed while you're away, with a cap on offline growth." Liam's planner (`plan/main`) is still empty, so these are defaults he can change.

## Global Constraints

- Server-authoritative: the client never decides growth, breeding, prices or coins.
- No em dashes in player-facing text, docs or commits. Keyboard and mouse, touch and gamepad.
- Old saves keep working: data version 3 adds an empty pond.
- Offline growth is capped (8 hours) so leaving the game for a week is no better than leaving it overnight.

## Rules (the numbers)

- Capacity 6 fish. Only fish from the bag can go in (no buying fish).
- Growth: each fish closes 30 percent of the gap to its species' maximum length per hour: `cm = max - (max - cm) * exp(-0.3567 * hours)` (0.3567 = -ln 0.7). Weight and price follow from length with the same formulas as a catch.
- Breeding: a species with at least two grown fish (at least 60 percent of the way from min to max length) has a 50 percent chance every 30 minutes of pond time to add one young fish at minimum length, if there is space.
- Ticking: on load, time since the last tick, capped at 8 hours; while online, every 30 s with real elapsed time.
- Selling from the pond pays `FishLogic.priceFor` at the fish's current weight. Release removes the fish and pays nothing.

## Review Focus

1. Pond full: Keep is refused with a clear message and the bag fish stays in the bag.
2. Player gone for days: growth and breeding use at most 8 hours.
3. Clock going backwards (negative elapsed): treated as zero, nothing shrinks.
4. Index out of range or stale (two quick clicks on Sell): refused, no coins paid twice.
5. A fish already at maximum length keeps its size and price; breeding never exceeds capacity.

### Task 1: PondLogic and data version 3

**Files:** Create `src/ReplicatedStorage/Shared/PondLogic.luau`, `src/ServerScriptService/Tests/PondLogic.spec.luau`; modify `Config.luau`, `Inventory.luau` (new player and v3 reconcile).

**Interfaces:**
- Data gains `pond = { fish: {PondFish}, lastTick: number, capacity: number }`; PondFish = `{ id, name, cm, kg, price, bornHere: boolean }`.
- `PondLogic.grow(fish, species, hours) -> ()` (updates cm, kg, price in place)
- `PondLogic.tick(pond, seconds, rng, now) -> { string }` (grows every fish, rolls breeding per 30 minutes, returns names of fish born; seconds clamped to 0 .. `Config.POND_OFFLINE_CAP`)
- `PondLogic.keep(data, bagIndex) -> (ok, msg)`, `PondLogic.sell(data, pondIndex) -> (ok, msg, coins)`, `PondLogic.release(data, pondIndex) -> (ok, msg)`
- Config: `POND_CAPACITY = 6`, `POND_GROW_RATE = 0.3567`, `POND_BREED_EVERY = 1800`, `POND_BREED_CHANCE = 0.5`, `POND_OFFLINE_CAP = 8 * 3600`, `POND_TICK = 30`.
